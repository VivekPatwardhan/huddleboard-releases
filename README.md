# HuddleBoard releases

Installable builds of HuddleBoard. This repo only holds releases.

**Android TV:** install the *Downloader* app on the TV, then open `huddleboard-app.web.app/tv.apk`.
Or download `HuddleBoard-TV.apk` from the [latest release](../../releases/latest) and copy it to the TV on a USB stick.

Phones and PCs need no install: open https://huddleboard-app.web.app (Chrome → Install app).
